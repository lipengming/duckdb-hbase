# examples — 使用示例

本目录提供可直接运行的最小示例，作为文档与集成测试的共同来源。

| 子目录 | 内容 |
| --- | --- |
| `sql/` | DuckDB CLI 示例：建连、`hbase_scan()` 查询、缓存管理 |
| `python/` | Python API 示例：连接、查询、缓存统计 |
| `config/` | Gateway 配置样例（脱敏，指向本地/测试集群） |

## 约定

- 示例中的地址、表名、列族一律使用占位值或本地环境，**不得**提交真实集群信息与凭据。
- 示例随 `docs/user-guide.md` 同步更新；示例变更需保证文档中的命令仍可执行。
- 每个示例文件头部用注释写明前置条件（DuckDB 版本、Gateway 是否已启动、所需配置）。
